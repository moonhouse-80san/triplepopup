팝업 모듈 관리

사이트에 노출되는 레이어 팝업을 관리합니다.
모듈 설정과 동작 모듈설정은 화면 오른쪽에 따라다니는 저장 버튼으로 저장합니다.

모듈 설정
초
화면에 보이는 수보다 팝업이 많으면 오른쪽에서 왼쪽으로 무한 반복
px
비워 두면(기본) 위의 가로 배너 수에 맞는 폭으로 자동 표시됩니다. 직접 입력하면 카드 1장의 가로폭(180~900)을 고정합니다.
일
팝업창이 보이지 않는 날 수 (기본 1이 하루입니다.) 2 이상이면 팝업에 'N일간 닫기'로 표시됩니다.
초
팝업이 뜬 뒤 이 시간이 지나면 각 배너가 자동으로 닫히고, 모든 배너가 닫히면 팝업이 끝납니다 (0~3600, 기본 0 = 자동으로 닫지 않음). 배너 편집의 '배너 자동 종료 Time'이 있으면 그 배너는 배너 설정을 따릅니다. 자동으로 닫힌 경우에는 다음 방문 때 다시 표시됩니다.
배너 관리 1~6번 순서대로 표시

각 배너의 등록·수정 버튼을 누르면 아래에 편집 영역이 펼쳐집니다. 왼쪽 손잡이를 드래그하여 순서를 바꿀 수 있고, 화면에 보이는 수보다 많이 활성화하면 오른쪽에서 왼쪽으로 무한 반복됩니다.
텍스트 입력란 오른쪽 지구본 아이콘을 누르면 라이믹스 다국어를 설정할 수 있고, 접속 언어에 맞는 문구가 팝업에 표시됩니다.
상태의 활성·비활성 배지를 누르면 해당 배너의 노출 상태를 바로 전환할 수 있습니다.

가로 배너 수는 한 화면에 나란히 보이는 배너 수입니다.
수가 적을수록 배너가 크게 나오고, 화면이 좁은 기기에서는 자동으로 줄어듭니다.

유튜브 16:9 비율을 고르면 영상이 잘 보이도록 배너 폭이 더 넓어집니다.
